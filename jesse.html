How to run the RAM script
  1. Download ram-report.zip above, then right-click it → Extract All. The password is blue
  2. Double-click ram-report.bat
  3. A black window opens and prints the answer
  4. It saves ram-report.txt to your Desktop — paste what’s in it into the thread

Windows will probably warn you. A blue box saying “Windows protected your PC.” That’s only because the file came from the internet — it isn’t a sign anything is wrong. Click More info, then Run anyway.

What it does

It only reads what Windows already knows about your memory. It installs nothing, changes nothing, and never touches the internet. It doesn’t need admin rights.

You can read the whole thing before you run it — right-click ram-report.bat → Open with → Notepad, and every line is there in plain English. Get in the habit of doing that with anything you download. Including from me.

Don’t want to download anything?

Press Windows key, type powershell, hit Enter, then paste this in:

$t=@{24='DDR3';26='DDR4';34='DDR5';35='LPDDR5'};$a=Get-CimInstance Win32_PhysicalMemoryArray;$m=@(Get-CimInstance Win32_PhysicalMemory);"Board: "+(Get-CimInstance Win32_BaseBoard).Product;"Total: {0} GB in {1} of {2} slots" -f (($m|Measure-Object Capacity -Sum).Sum/1GB),$m.Count,$a.MemoryDevices;$m|Select-Object @{n='Slot';e={$_.DeviceLocator}},@{n='GB';e={[int]($_.Capacity/1GB)}},@{n='Type';e={$t[[int]$_.SMBIOSMemoryType]}},@{n='Speed';e={"$($_.Speed) MT/s"}},Manufacturer,PartNumber|Format-Table -AutoSize

Then paste whatever it prints into the thread.

If none of that works

  • Right-click ram-report.bat → Run as administrator, try again
  • Or grab CPU-Z (free, cpuid.com) — the SPD tab names every slot, even the empty ones
  • Or just call me. Seriously. This is literally my job

One thing worth knowing

DDR5 is picky about mixing. Two sticks that weren’t sold together as a matched pair can refuse to run at full speed, or stop the PC booting until XMP/EXPO gets switched off in the BIOS. So the safest buy is the identical part number to what’s already in there — which is exactly what the script tells us.

Also: with two sticks, most boards want them in A2 and B2 (2nd and 4th slot from the CPU), not A1 and B1. Sounds wrong. Isn’t.
